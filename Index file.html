Why do customers leave?

A telecom company loses a slice of its customer base every month. This notebook walks through the whole job — loading the data, splitting it, growing a decision tree, and checking whether the tree is any good — with 240 customers you can poke at directly. Run the cells in order.

240 customers 6 features 1 target: Churn model: DecisionTreeClassifier
Everything here runs in your browser. The dataset is generated from a fixed seed and the tree is a real CART implementation — same gini criterion, same greedy splitting, same prediction rule that scikit-learn uses — so the numbers you see match the code shown in each cell.
